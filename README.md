# photo_gallery

# 📸 Photo Gallery Website

A clean and responsive **Photo Gallery Web Page** built using **HTML & CSS**.
This project displays images in a modern grid layout with smooth hover effects.

---

## 🚀 Features

* 📱 Fully Responsive Design
* 🎨 Modern Grid Layout
* 🔍 Image Hover Zoom Effect
* ⚡ Fast & Lightweight
* 🌐 Works directly in browser (no setup needed)

## ▶️ How to Run

1. Download or clone the repository:

```
git clone https://github.com/your-username/photo-gallery.git
```

2. Open the folder

3. Double click **index.html**
   OR open with Live Server

---

## 🌍 Live Demo (GitHub Pages)

👉 Enable GitHub Pages:

* Go to **Settings**
* Click **Pages**
* Select branch: `main`
* Save

Your site will be live at:

```
https://your-username.github.io/photo-gallery/
```

---

## 📸 Customization

* Replace image links:

```html
<img src="your-image.jpg">
```

* Change gallery layout in CSS:

```css
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
```
